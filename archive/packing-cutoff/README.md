# No universal packing cutoff

For every cutoff $k\ge2$, two patterns of the same length and overlap have equal prescribed packing counts through $k$ occurrences and different counts at $k+1$. The local construction uses patterns of length $4k$ and gives an exact formula for the first difference.

Cinna Davis posted the negative answer on November 26, 2026 with a length-$3k+1$ construction. The local manuscript is a later derivation, checked by exact integer counts.
