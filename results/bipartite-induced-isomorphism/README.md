# The proposed boundary for induced subgraph isomorphism

Alecu, Lozin and Malyshev ask whether linear forests are the unique obstruction to polynomial-time induced subgraph isomorphism in hereditary subclasses of bipartite permutation graphs. Their Conjecture 2 asserts, under $\mathrm P\ne\mathrm{NP}$, that such a subclass is ISI-hard exactly when it contains every linear forest. Equivalently, it predicts a polynomial-time algorithm on the $P_k$-free bipartite permutation graphs for every fixed $k$. The source restricts the host and permits any input pattern. Both graphs in the hardness construction meet the restriction. [Original preprint, §5, Conjecture 2](https://arxiv.org/pdf/2010.14467v1#page=18) · [Journal version, §5](https://doi.org/10.1002/jgt.23011)

Induced subgraph isomorphism is NP-complete even when the pattern is a star forest and each host component has two vertices meeting every edge. The constructed bipartite permutation graphs exclude the six-vertex path. Together with the source algorithm this gives the exact boundary for every forbidden path. The problem is polynomial-time solvable through five vertices and NP-complete from six onward. [Proof and construction](PROOF.md) · [Prior work and review](AUDIT.md)

For hereditary bipartite classes closed under disjoint union and independent twin duplication, the same proof gives a full criterion. Containing $P_5$ gives NP-hardness, while excluding it gives a polynomial algorithm. [Closure criterion](PROOF.md#a-classification-for-classes-closed-under-disjoint-union-and-twin-duplication)

Ordinary stars represent the items to be matched, and larger stars determine which pairs of items can be used at each target weight. An independent construction places two balanced complete bipartite graphs into a single explicitly ordered graph whenever the sum of their sizes fits. [Alternative reduction](PREFIX-SUFFIX.md)

Lean proves the uncolored packing criterion for graphs of arbitrary size, checks the host permutation orders and path exclusion, and states the conjecture using a polynomial-time Turing machine on the two adjacency matrices. The independent review covers the complete written complexity proof. The verifier compares literal induced subgraphs with the capacity rule and checks the reduction against exact numerical matching.
