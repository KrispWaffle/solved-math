# Counterexamples to minimal hardness for folded linear forests

**Theorem.** There is an almost periodic binary word and a graph on its two letters for which the folded class is not a minimal NP-hard class for induced subgraph isomorphism. There is such a counterexample with a computable word and decidable class membership. If $\mathrm P\ne\mathrm{NP}$, the word can be chosen so that induced subgraph isomorphism on its promised hosts is neither polynomial-time solvable nor NP-hard, yet every proper hereditary subclass admits a polynomial-time algorithm.

The theorem resolves Conjecture 3 in the journal version of Alecu, Lozin and Malyshev. We interpret NP-hardness under polynomial-time many-one reductions that produce a host in the class on every input. A polynomial-time algorithm on the class may assume that the host satisfies the promise. The pattern is arbitrary. [Journal, §§4.1 and 5](https://doi.org/10.1002/jgt.23011)

## A fold with readable letters

For an irrational number $1/3<\alpha<2/3$, take the binary word with letters
```math
w_i=\lfloor(i+1)\alpha\rfloor-\lfloor i\alpha\rfloor,\qquad i=0,1,2,\ldots.
```
Use the two-letter graph whose only edge is a loop on $1$. Starting with the one-way infinite path, toggle adjacency between distinct positions both carrying $1$. Denote the class of finite induced subgraphs by $C_\alpha$. The number of ones in any consecutive block of length $l$ starting at $i$ is $\lfloor(i+l)\alpha\rfloor-\lfloor i\alpha\rfloor$, and consequently differs from $l\alpha$ by strictly less than one.

For completeness, a finite binary word $v$ of length $l$ with prefix sums $h_0=0,h_1,\ldots,h_l$ occurs exactly when
```math
\max_{0\le j\le l}(h_j-j\alpha)-\min_{0\le j\le l}(h_j-j\alpha)<1.
```
Indeed its possible starting phases $t$ obey $h_j\le t+j\alpha<h_j+1$ for every $j$. Intersect these half-open intervals, including $0\le t<1$ at $j=0$. A nonempty intersection has positive length. Some positive orbit iterate of the irrational rotation has phase in its interior. Each such interval is hit with bounded gaps: the inverse translates of its open interior cover the circle by density of the forward orbit from every point, and compactness gives a finite subcover. This proves almost periodicity in the source’s sense. This coding and recurrence are classical properties of mechanical words. [Morse and Hedlund](https://doi.org/10.2307/2371431)

Fix any realization of a finite host and write $D_1$ for the selected one-letter vertices. A zero-letter vertex has degree at most two. A one-letter vertex has at least $|D_1|-3$ neighbors, since among the other ones it can miss only its two immediate path neighbors. Consequently if $|D_1|\ge6$, then
```math
D_1=D(G):=\{v:\deg_G(v)>2\}.
```
Whenever $|D(G)|\ge6$ this formula is valid in every representation, because $D(G)\subseteq D_1$. Toggling pairs inside $D(G)$ restores the linear forest of consecutive selected positions. In each of its components, the marked vertices have the frequency bound above, with either orientation of the path. When $|D(G)|<6$, the actual number of ones is at most five, so every true path component has fewer than 18 vertices by $\alpha>1/3$ and the same discrepancy bound.

## An unconditional obstruction to minimality

A computably enumerable family of valid hosts with unbounded true component lengths computes $\alpha$. For precision $2^{-s}$, enumerate its finite graphs, retain those with $|D(G)|\ge6$, toggle, and wait for a restored component of length $l\ge 2^s$. Output its marked count divided by $l$. The search terminates because runs in the other hosts have bounded length. Its error is less than $1/l$. The whole class contains the folds of contiguous blocks of every length. Hence $C_\alpha$ cannot be computably enumerable if $\alpha$ is noncomputable.

Every minimal NP-hard hereditary host class is computably enumerable. Fix a polynomial-time reduction from SAT witnessing hardness. Enumerate its host outputs over all finite input strings, then all their finite induced subgraphs and relabelings. The resulting hereditary subclass still contains every output host of that very reduction, so it is itself NP-hard. Minimality forces it to equal the original class. Choosing any noncomputable irrational slope in the displayed interval now disproves the journal conjecture, independently of $\mathrm P$ versus $\mathrm{NP}$.

There is also a cardinality proof of the unconditional conclusion. Two different slopes in this interval give incomparable classes. If $C_\alpha\subseteq C_\beta$, take an entire folded block of length $n$ at slope $\alpha$, large enough to have at least six ones. In a realization at $\beta$ the intrinsic degrees recover the same letters. Unfolding gives an injective unit-step walk of $n$ vertices on the integer path. Its image is a consecutive interval of length $n$: its largest and smallest positions differ by at most $n-1$, and there are $n$ distinct positions. The common count $m$ of ones satisfies both $\lvert m-n\alpha\rvert<1$ and $\lvert m-n\beta\rvert<1$. Taking arbitrarily large $n$ forces $\alpha=\beta$.

There are uncountably many irrational slopes in this interval and at most countably many minimal NP-hard hereditary classes, since each such class is exactly the hereditary hull of one reduction program. This gives an almost periodic counterexample without any computability or complexity hypothesis. Lean checks this cardinality proof from the graph definition and an explicit clocked Turing-machine model. ## Bounded path components give a polynomial algorithm

Fix $L$. Suppose a host can be written as a fold of a two-colored linear forest with at most $L$ vertices per component. The algorithm needs this bound and the graph alone. Enumerate candidate sets of ones consisting of the set of vertices of degree greater than two and all subsets of at most five vertices. Do this for both the host and the arbitrary input pattern. For each pair of guesses, toggle all edges between ones inside each graph and color according to the guess. Discard guesses whose resulting graph is not a linear forest with component order at most $L$.

For the remaining pair, solve the color-preserving induced embedding problem. The colored paths of length at most $L$ vertices give finitely many component types up to reversal. For each host component enumerate its at most $2^L$ induced subsets and count the resulting components of each type. A dynamic program over the host components stores which vectors of pattern component counts can be realized, discarding any vector that exceeds the required counts. If there are $q_L$ types, there are at most $(|H|+1)^{q_L}$ vectors for a pattern $H$. For fixed $L$ all these operations are polynomial time.

A successful embedding after toggling preserves both colors and every adjacency and nonadjacency, so it is an induced embedding before toggling too. Conversely, any original embedding pulls the true colors of the host back to the pattern. If there are at least six ones on either graph, its degree test recovers them; if fewer, its true set is among the small guesses. Deleting vertices from a bounded linear forest gives another such forest. Therefore the algorithm accepts exactly the embeddable patterns.

For noncomputable $\alpha$, every computably enumerable family of hosts inside $C_\alpha$ has bounded true run lengths by the preceding extraction. A polynomial SAT reduction would have such a family as its range and therefore give a polynomial-time SAT algorithm. This shows $C_\alpha$ is not NP-hard if $\mathrm P\ne\mathrm{NP}$. The counterexample to minimality above did not need this hypothesis.

## Every proper hereditary subclass admits a polynomial algorithm

Take a graph $F$ in $C_\alpha$ outside a given proper hereditary subclass. Some finite interval of positions spans an occurrence of $F$. Let $v$ be the word on that whole interval. Every sufficiently long factor of the infinite word contains $v$ by almost periodicity. If a host has a true restored component at least that long, its consecutive positions contain an induced copy of $F$, including all edges affected by the fold. Such a host cannot belong to the subclass. Hence a constant bound on component orders works throughout the subclass. The bounded-path algorithm applies to arbitrary input patterns. With graph orders supplied as part of the input, first reject a pattern larger than its host. The running time for all remaining pairs is polynomial in the host order alone as well.

## Hardness for periodic words

Fix a rational slope $p/q$ in the same interval in lowest terms. Its mechanical word is periodic with period $q$. The promised-host problem for this fold is NP-hard by a reduction from unary 3-Partition. An input has $3m$ positive weights $a_i$ with total $mB$ and $B/4<a_i<B/2$. The aim is to partition them into triples of sum $B$. This restricted unary problem is NP-complete. [Garey and Johnson, problem SP15](https://perso.limos.fr/~palafour/PAPERS/PDF/Garey-Johnson79.pdf)

Set $d=12q$. Start with a host of $m$ disjoint paths on $dB-1$ vertices each and a pattern having one path on $da_i-1$ vertices per item. Color every path with the periodic word from phase zero, and fold by toggling pairs of ones over each *entire graph*, including pairs in different paths. Disjoint occurrences starting at multiples of $q$ with unused positions between them realize both graphs in the periodic folded class. The output size is polynomial since the input is unary and $q$ is fixed. Empty and malformed inputs can be sent to fixed appropriate graph pairs.

For a nonempty valid instance the pattern contains at least six ones, since even a shortest path contains at least eleven whole periods. In an induced embedding its image has the same degrees *inside the image*. All the pattern ones have degree above two, so the image has at least six true ones. The degree criterion on the image identifies every one and every zero there. Unfolding therefore embeds the original path forest into the host path forest with colors preserved.

If a host path receives $s>0$ items, their intervals require at least one unused vertex between successive intervals. They occupy a span of at least $d\sum a_i-s+(s-1)=d\sum a_i-1$ vertices. The sum of their weights is at most $B$. The total weight $mB$ makes every bin tight, and the strict bounds on each weight make each group a triple. Conversely, place a matching triple in any order, with a one-vertex gap between items. The starts differ by multiples of $d$ and thus have the prescribed phase. The colors and all induced edges match in the unfolded and folded graphs. This proves the reduction.


## A computable slope and a decidable counterexample

For any graph $G$ on $n$ vertices, membership in $C_\alpha$ can be determined by a finite calculation locally constant in irrational $\alpha$ away from a computable finite set of rationals. Enumerate all vertex-colorings, then toggle to recover the candidate linear forest. In each component, test whether its colored word in at least one orientation is a factor, using the strict spread inequality in the first section. These tests suffice jointly: choose the individual occurrences successively in the infinite word with a skipped position between them, using recurrence. The fold then also gives the prescribed edges between components. Each inequality for a word of length at most $n$ has rational boundary points with denominators at most $n$, since it compares two integer prefix sums differing by $\pm1$ after subtraction. Thus rational interval arithmetic tests membership on every open cell between such points. For a computable irrational $\alpha$, refining its rational approximations eventually locates it in its cell, giving decidable graph membership.

At a rational slope the periodic factor dictionary is also decidable by testing the $q$ possible starting phases. Each word occurring at that slope has prefix spread strictly less than one, by its actual phase and the half-open interval test. This strict inequality persists in a neighborhood of the rational. Thus each finite graph in the periodic folded class belongs to every irrational-slope class in some effective open neighborhood. To find one, take an actual finite representation and impose its finitely many strict word inequalities.

Assume $\mathrm P\ne\mathrm{NP}$. We construct one computable irrational slope by shrinking closed rational intervals inside $(1/3,2/3)$. Enumerate both clocked polynomial-time transducers from strings to graph pairs and clocked polynomial-time decision algorithms on graph pairs. A fixed total decoding handles malformed outputs. For each requirement use the open interior $I$ of the current interval.

**Defeat a SAT reduction.** The following argument also excludes ordinary many-one reductions to the total language of pairs $(G,H)$ satisfying both $G\in C_\alpha$ and $H$ embeds in $G$. Dovetail all binary inputs and all open rational subintervals of $I$. SAT and unrestricted finite induced embedding can both be decided exhaustively. Look for a positive input with an incorrect embedding answer, a positive input whose host is excluded on an irrational-slope subinterval, or a negative input whose pattern embeds and whose host belongs on an irrational-slope subinterval. The slope-cell membership calculation above makes these searches effective.

If no witness existed, each positive output would embed and its host would belong at every irrational slope in $I$. Each negative output that embeds would have its host outside every such class. Choose distinct irrational slopes $\beta,\gamma$ in $I$. In any host common to both having at least six high-degree vertices, each canonically restored component of order $l$ satisfies $l\lvert\beta-\gamma\rvert<2$. Hosts with fewer high-degree vertices have true components shorter than 18. Choose a single integer $L$ at least both 18 and $2/\lvert\beta-\gamma\rvert$.

There is a polynomially recognizable class $T$ consisting of graphs that have a representation by factors of the $\beta$ word of order at most $L$. Guess the high-degree set or one of the polynomially many subsets of size at most five, unfold, and check each path against the finite dictionary of these factors, allowing reversal. This dictionary is a fixed finite table. The intersection of all the slope classes in $I$ lies in $T$, and $T$ lies in $C_\beta$. Accept an output pair exactly when its host is in $T$ and the bounded-path algorithm accepts. This would decide SAT in polynomial time, since all positive outputs pass both tests and any negative output passing the embedding test has host outside $T$. The contradiction guarantees a witness. Restrict to its subinterval, or retain $I$ for an intrinsic false negative. Any promise-preserving reduction would also be a reduction to the total language, so this stage excludes both conventions.

**Defeat a polynomial decision algorithm.** Choose any rational $p/q$ in $I$. The algorithm must err on some pair with host in the corresponding periodic folded class. Otherwise the unary 3-Partition reduction would give a polynomial-time decision procedure. Enumerate finite graph pairs until finding such an error, using decidability for this periodic class and for induced embedding. Restrict to an open subinterval of $I$ throughout which this finite host remains present for irrational slopes. Its embedding answer depends only on the two graphs, so the same error persists.

After either kind of requirement, choose a positive-length closed rational interval strictly inside the remaining open interval, of length at most $2^{-e-1}$ at stage $e$, omitting the $e$th rational in a fixed enumeration. This gives a computable irrational $\alpha$. Its word is computable and membership in $C_\alpha$ is decidable. Every polynomial decision algorithm errs on a promised host and every polynomial-time SAT reduction fails. Induced embedding has a polynomially checkable witness on promised inputs. Hence this promised problem is intermediate under $\mathrm P\ne\mathrm{NP}$. The proof of nonhardness also applies to the total language. Membership in NP for total recognition is not used here.

If $\mathrm P=\mathrm{NP}$, take any computable irrational in the same interval. The proper hereditary subclass of edgeless graphs is already NP-hard in this case. A SAT decider can send positive and negative inputs to fixed yes and no edgeless-host instances respectively. Every $C_\alpha$ contains all finite edgeless graphs by taking nonconsecutive zero positions, and contains an edge by taking two nonconsecutive ones. This gives a decidable counterexample to minimal NP-hardness in either case. Under $\mathrm P\ne\mathrm{NP}$ the constructed example is itself minimal among hereditary classes lacking a polynomial algorithm, the different notion used in the preprint. The universal conjecture in that version is left open.
