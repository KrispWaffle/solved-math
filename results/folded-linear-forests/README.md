# Folded linear forests and minimal hardness

Alecu, Lozin and Malyshev conjectured that every class of folded linear forests is minimal NP-hard for induced subgraph isomorphism. **The journal conjecture is false.** The counterexamples use the infinite path labeled by an irrational rotation word. Toggling adjacency between pairs of ones produces uncountably many distinct hereditary graph classes. Each minimal NP-hard class, however, must be generated by the hosts output by one polynomial-time reduction. [Journal §5, Conjecture 3](https://doi.org/10.1002/jgt.23011) · [Proof](PROOF.md)

Lean proves the unconditional disproof with a finite tape alphabet and transition table, a polynomial clock, literal finite graph encodings, arbitrary input patterns and a promised host on every positive and negative SAT input. The fold allows every finite alphabet, every symmetric letter relation with loops, and every almost periodic word. [Formal conjecture and theorem](../../lean/SolvedMath/FoldedMinimalHardness.lean) · [Almost periodicity](../../lean/SolvedMath/FoldedWords.lean) · [Degree recovery](../../lean/SolvedMath/FoldedGraphs.lean) · [Slope recovery](../../lean/SolvedMath/FoldedSlope.lean)

The written proof also gives a computable word with decidable class membership. Assuming $\mathrm P\ne\mathrm{NP}$, it can be chosen so that the promised problem is neither polynomial-time solvable nor NP-hard, while every proper hereditary subclass admits a polynomial-time algorithm. Ordinary many-one reductions to the total language also fail. These effective refinements have independent written review. The 2020 preprint defines hardness as the absence of a polynomial-time algorithm. Its universal conjecture under that definition remains open here. [Preprint §5](https://arxiv.org/pdf/2010.14467v1#page=16)
