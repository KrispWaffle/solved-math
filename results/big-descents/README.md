# Schur positivity of big descents

For permutations of a fixed length and exact longest increasing subsequence length, the quasisymmetric function recording big-descent positions has nonnegative Schur coefficients. The local manuscript gives a formula for those coefficients using pairs of tableaux.

Cinna Davis posted the positivity theorem, including the exact-length refinement, on November 26, 2026. The local manuscript is a later derivation. Its verification consists of the written argument and exact finite checks.
