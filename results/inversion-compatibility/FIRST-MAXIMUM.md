# When the normalized forbidden pattern starts with its maximum

In the compatibility test, fix a boundary choice and normalize it by inverse or reverse-complement to deletion of the first point. Let $q$ be the forbidden singleton pattern in those coordinates. Say that this orientation has a witness if an indecomposable input avoiding 1324 and $q$ acquires an occurrence of $q$ using this normalized move, with the boundary priority carried along from the original source map. The four orientations need not give the same answer individually. [Source conditions, printed Theorems 7.8–7.9](https://arxiv.org/pdf/2604.01143v2#page=29)

**Theorem.** Suppose $q$ avoids 1324, has length $h\ge2$ and begins with its maximum $h$. A witness for this orientation exists exactly when the tail of $q$ has at least three direct-sum components. This condition works for both early and late boundary choices. A decomposable input cannot newly acquire $q$.

The last assertion follows because $q$ is indecomposable and the decomposable move only inserts a singleton component. For the forward direction, write the normalized input as in the [general proof](PROOF.md), with pivot $X$, last-component crossing point $C$, and a new middle singleton in the image. Any new $q$ must use $X$: without the pivot it would be an indecomposable occurrence in a single unchanged end. It must omit $C$, which is above $X$ in the image. It must use a new middle point, since the old points other than $C$ retain all their comparisons. If no selected point is in the first component, replace the earliest selected middle point by any point of that component and use the old middle for the rest. If no selected point is in the last component, replace the last selected middle point by $C$, below the pivot in the input. Either replacement recreates $q$ in the input. Thus the tail of the selected occurrence uses three nonempty blocks in direct-sum order: points of the first component, the increasing middle, and points of the last component. It has at least three components.

Conversely write the tail of $q$ as $\sigma\oplus I_m\oplus\tau$ with $m\ge1$ and nonempty indecomposable ends, using the component description of a 1324-avoider. For an early boundary choice, take an input of length $h$ starting with its maximum and with standardized tail $\sigma\oplus I_{m-1}\oplus(1\ominus\tau)$. The tail avoids 1324, and its last component avoids 213. The first maximum introduces no 1324. Its tail has one fewer component than the tail of $q$, so the input avoids $q$. Deleting the first entry succeeds; the other early choice cannot succeed simultaneously by the priority theorem. In the image, discard the maximum of the last component. The remaining word is $q$.

For a late boundary choice use an input of length $h+1$ with first point $X$ of rank $h$ and standardized tail $\sigma\oplus I_{m-1}\oplus(21\ominus\tau)$. Only the first point $Z$ of the last component exceeds $X$. A 1324 cannot start at $X$ with only one larger successor, and the tail has the required two-end form. A length-$h$ occurrence omitting $X$ would be decomposable. One starting at $X$ would have to omit $Z$, leaving a tail with one fewer component than required. Thus the input avoids $q$.

Deleting $Z$ leaves the maximum $X$ at the front, preventing any cut. If the last position is deleted, the last component remains connected and contains a point below $X$. When $|\tau|=1$ the remaining last component is 21, otherwise both skew sides survive. The earlier parts of the word all connect to $X$. Hence neither earlier competing deletion succeeds. After the actual prescribed growth, discard the first two points from the last component. This gives the required $q$. Undoing the symmetry proves the claim in every orientation. ∎

The late second-largest case and the complete classification appear in the [singleton theorem](CLASSIFICATION.md).
