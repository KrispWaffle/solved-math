# Source, priority and independent review

## Exact statement

Vatter’s Question 4.3 in the published version asks **which infinite classes have a convergent derangement proportion**. The subject of this result is the distinct unnumbered question in the next paragraph asking which limit values occur. A different class may witness each value. Each length is sampled uniformly from the distinct members of that class. The theorem gives a limit along every length and includes zero, one and all irrational interior values. [Vatter, §4, p. 18](https://arxiv.org/pdf/2602.16355v4#page=18)
